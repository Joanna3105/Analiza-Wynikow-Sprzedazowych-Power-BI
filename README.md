# Projekt 3: Analiza wyników sprzedażowych w Power BI

## Opis projektu

Projekt obejmuje interaktywny dashboard analizujący:
- sprzedaż,
- rentowność,
- regiony,
- produkty,
- klientów.

## W projekcie wykorzystano

- Power BI,
- Power Query,
- DAX,
- modelowanie danych.

## Zakres prac

- przygotowanie i transpozycję danych w Power Query,
- przygotowanie tabeli kalendarza,
- model danych i relacje,
- miary DAX,
- interaktywne wizualizacje,
- drill down i tooltipy,
- nawigację między stronami oraz fragmentatory i filtry,
- analizę danych oraz wnioski i rekomendacje.

## Zawartość repozytorium

- dashboard.pbix
- dane.xls
- zrzuty ekranu dashboardu.pdf
##### Do projektu dołączyłam również wnioski, pokazując szerzej swoją interpretację otrzymanych wyników - są one aktualne na obecny stan danych
